How it works

Streaming and downloading uses WebTorrent, which fetches pieces from other people's browsers (WebRTC peers) and from web seeds. Torrents shared only by desktop apps such as qBittorrent can't be reached from a web page, so some magnet links will never load here.

Direct links appear when a torrent includes a web seed: a normal https:// address for each file that anyone can download. Downloads made in this page are kept in memory until saved, so very large files (over about 2 GB) may fail, especially on phones.

.torrent → magnet happens instantly. The page reads the file and hashes its info section to build the link.

Only stream, download or share torrents you have the right to.

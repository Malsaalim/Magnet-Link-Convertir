How it works

.torrent → magnet happens instantly. The page decodes the file, hashes its info section (SHA-1 for v1, SHA-256 for v2), and builds the link with the name, size, trackers and web seeds.

Magnet → .torrent needs the torrent's metadata, which only peers have. The page connects to browser-capable (WebRTC) peers and saves the file as soon as the metadata arrives. Torrents seeded only by desktop clients may never answer; in that case, open the magnet link in a desktop client such as qBittorrent and export the .torrent from there.

Only convert torrents you have the right to share.
